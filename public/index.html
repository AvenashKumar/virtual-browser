How it works

    
Stage 1, this build: a headless Chrome on Cloudflare's network opens the link and sends back a screenshot, the text, and the links. Your browser never touches the site.

    
Stage 2, later: a full interactive browser streamed to you as video, where you can click and type. That needs a server running Chrome per session.

    
Limits: the remote browser is identifiable as automation, so some sites will block it. Sessions are short, and private or local addresses are blocked. Free Browser Run time is 10 minutes a day.
