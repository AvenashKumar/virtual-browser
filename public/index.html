How it works

    
Stage 1, safe preview: a headless Chrome on Cloudflare's network opens the link and sends back a screenshot, the text, and the links. Your browser never touches the site.

    
Stage 2, interactive session: start a session and the live page is streamed to you in this window, so you can click and type inside it. End the session and the remote browser is closed and wiped.

    
Limits: the remote browser is identifiable as automation, so some sites will block it. Sessions last up to 20 minutes, and private or local addresses are blocked. Free Browser Run time is 10 minutes a day.
